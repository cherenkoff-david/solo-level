# Референс: Reflect (приложение)

## Откуда

- Продукт: Reflect — приложение для заметок (`https://reflect.app/`).
- Экран: интерфейс приложения (не лендинг). Каталог экранов: Mobbin, `Reflect Web`.
- Дата разбора: ноябрь 2026.

Оговорка о методе: палитра **лендинга** reflect.app была извлечена из его CSS (см. §«Что найдено»).
Экраны **приложения** на Mobbin доступны за логином и при разборе не просматривались — суждение о
приложении здесь опирается на публичное описание и общий язык продукта, а не на попиксельный разбор.
Это ограничение честно фиксируется: если позже появятся скриншоты приложения, разбор уточняется.

## Что найдено (факты, лендинг reflect.app)
- Фон лендинга: `#030014` — глубокий **фиолетово-чёрный**.
- Акценты лендинга: фиолетово-сиреневое семейство `#ba9cff`, `#9382ff`, `#5046e4`; градиентные
  текстовые бейджи (`#e59cff → #ba9cff → #9cb2ff` через `background-clip: text`).
- Приём: dark glassmorphism — полупрозрачные белые подложки `rgba(255,255,255, 0.01…0.12)`,
  `backdrop-filter: blur`, бордеры `rgba(255,255,255, 0.1)`.
- Шрифты: **Inter V** (400/500) + **AeonikPro** (дисплейный, 500).
- Радиусы: 8px (кнопки), 24px (карточки превью), 999px (pill).
- Размеры: самый частый текст 13/14/16px; межстрочные 20/24px; заголовки до 72px (лендинг).
- Явных токен-переменных нет — значения заданы литералами (типично для Qwik SSR).

## Что берём

- **Палитру**: глубокий фиолетово-чёрный фон `#030014`, лавандовый текст `#f4f0ff`, полупрозрачные
  стеклянные поверхности, тонкие светлые границы `rgba(255,255,255,.1)`.
- **Приём «стекло»** для верхнего хедера: полупрозрачный фон + `backdrop-blur`. (Взято после
  визуальной сверки: изначально планировалось не брать; на плоском фоне без стекла интерфейс
  выглядел мёртвым.)
- **Амбиентное свечение фона** — статичные радиальные градиенты, дающие глубину и работу стеклу.
- **Монохромные списки** и низкоконтрастные границы.
- **Спокойную типографику**: Inter, веса 400/500, мелкая база (13–14px) с крупными заголовками.
- **Радиусы 8px (контролы) и pill (999px)**.
- **Моно-числа** для данных (у нас — JetBrains Mono для XP/уровней).

## Что НЕ берём

- **Градиентные текстовые бейджи** (`background-clip: text`, `#e59cff → #ba9cff → #9cb2ff`) —
  декоративный градиент, один из опознаваемых «AI-приёмов».
- **Радужный градиент** (`#fc72ff → #8f68ff → #487bff → #2cd9ff → #2cffcc`).
- **Стекло «везде»**: полупрозрачные подложки на каждом блоке. Стекло — только там, где оно
  функционально (sticky-хедер, модальные слои).
- **Лендинговую подачу**: крупные заголовки-экраны (до 72px), маркетинговые секции. У нас рабочий
  экран, а не витрина.
- **Домен заметочника**: граф связей, backlinks, ежедневные заметки — у Solo другая структура.

## Итог

Reflect взят и как источник **цвета** (`#030014` + лаванда), и как источник **дисциплины и приёма
стекла**, но без декоративных градиентов и лендинговой подачи. Цвет и декор разделены намеренно:
первый берём, второй — нет. Стилистически ближайшие ориентиры по плотности — Linear и Raycast.
