# Дизайн-токены

Источник истины для значений: **документ (`tokens.md`) для человека, `@theme` в CSS — исполняемая
копия.** При расхождении правится код, документ обновляется.

Палитра — **принята после визуальной сверки** (первая гипотеза, тёплый нейтральный `#100f0d`,
отвергнута: читалась коричневой). Текущие значения — палитра Reflect (`#030014` + лаванда), взятая
как цвет без его декора (см. `references/reflect.md`).

Реализация: Tailwind 4 CSS-first (`@theme`), переменные семантические.

---

## 1. Цвет

### База (тёмная тема)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-bg` | `#030014` | Фон приложения (глубокий фиолетово-чёрный, как у Reflect) |
| `--color-surface` | `rgba(255, 255, 255, 0.03)` | Поверхности: карточки, стеклянные слои |
| `--color-surface-raised` | `rgba(255, 255, 255, 0.06)` | Поднятая поверхность: модальные окна, меню, hover |
| `--color-border` | `rgba(255, 255, 255, 0.1)` | Границы, разделители |
| `--color-border-strong` | `rgba(255, 255, 255, 0.2)` | Границы при наведении/фокусе |
| `--color-text` | `#f4f0ff` | Основной текст (лавандовый off-white) |
| `--color-text-muted` | `#efedfd99` | Вторичный текст, подписи |
| `--color-text-faint` | `#efedfd52` | Отключённый текст, метки |

Фон дополняется **амбиентным свечением** (два статичных радиальных градиента фиолетового и
синего, `background-attachment: fixed`). Это не декор ради декора: свечение даёт стеклянному хедеру
что размывать, иначе `backdrop-blur` не читается на плоском фоне.

### Акцент и статусы

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-accent` | `#ba9cff` | Лаванда. Интерфейс: навигация, фокус, активные элементы |
| `--color-accent-muted` | `rgba(186, 156, 255, 0.14)` | Подложка под интерфейсный акцент |
| `--color-progress` | `#f0a020` | Amber. **Только доменные числа** (XP, уровень, ступень) |
| `--color-progress-muted` | `rgba(240, 160, 32, 0.14)` | Подложка под прогресс |
| `--color-danger` | `#e5484d` | Отмена действия, ошибка |
| `--color-focus` | `#ba9cff` | Кольцо фокуса (совпадает с интерфейсным акцентом) |

Правило: **два акцента с разной ролью**. Лаванда — интерфейс (куда я могу нажать), amber — прогресс
(доменные данные). Amber не применяется к элементам интерфейса; лаванда не применяется к XP и уровням.

### Проверка контраста (до подтверждения скриншотом)

| Пара | Контраст (расчётно) | Норма |
| --- | --- | --- |
| `text #f4f0ff` на `bg #030014` | ~18:1 | ≥ 4.5:1 ✓ |
| `text-muted #efedfd99` на `bg #030014` | ~7:1 | ≥ 4.5:1 ✓ |
| `accent #ba9cff` на `bg #030014` | ~9:1 | ≥ 4.5:1 ✓ |
| `progress #f0a020` на `bg #030014` | ~9:1 | ≥ 4.5:1 ✓ |
| `text-faint #efedfd52` на `bg #030014` | ~2.8:1 | только для отключённого/декоративного |

Числа расчётные (WCAG 2.1, относительная яркость). Перепроверяются инструментом при вёрстке.

## 2. Типографика

| Токен | Значение |
| --- | --- |
| `--font-sans` | `Inter, system-ui, -apple-system, sans-serif` |
| `--font-mono` | `JetBrains Mono, ui-monospace, monospace` |

`font-feature-settings` для Inter: `"cv10" on, "ss01" on` (альтернативные глифы, как в референсе).
Для чисел — `font-variant-numeric: tabular-nums`.

### Размеры

| Токен | Размер / межстрочный | Назначение |
| --- | --- | --- |
| `--text-xs` | 12px / 16px | Метки, бейджи |
| `--text-sm` | 13px / 18px | Вторичный текст |
| `--text-base` | 14px / 20px | **Плотные списки** (привычки), основной UI |
| `--text-body` | 16px / 24px | **Просторные блоки** (прогресс), ввод |
| `--text-lg` | 18px / 26px | Подзаголовки |
| `--text-xl` | 22px / 28px | Заголовки разделов |
| `--text-2xl` | 28px / 34px | Крупные числа прогресса |
| `--text-3xl` | 36px / 42px | Главные метрики |

Веса: `400` (текст), `500` (акцент, активные элементы), `600` (заголовки). Жирнее — не используем.

**Входная страница `/welcome`** использует собственную шкалу из пяти размеров — `--lp-*` в
`src/styles/landing.css`: `13 / 16 / 20 / 46 / 84` px (заголовки — через `clamp`, чтобы не ломать
переносы на узких экранах). Это не новые токены приложения, а локальный масштаб страницы: рабочие
экраны продолжают жить на шкале выше.

## 3. Радиусы

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--radius-sm` | 6px | Чипы, мелкие элементы |
| `--radius-md` | 8px | **Кнопки, контролы** |
| `--radius-lg` | 12px | **Карточки, панели** |
| `--radius-full` | 999px | Pill-элементы, круглые индикаторы |

## 4. Отступы

Шкала с шагом 4: `4 / 8 / 12 / 16 / 24 / 32 / 48`. Промежуточных значений «на глаз» не вводим.

## 5. Границы и тени

- Граница: `1px solid var(--color-border)`. Толстых рамок нет.
- Тень для всплывающих слоёв: `0 8px 24px rgba(0, 0, 0, 0.4)` — только для модалок и меню.
- Карточки тенью не отделяются: только границей и фоном (`surface` на `bg`).

## 6. Движение

Базовые длительности интерфейса:

- `120ms` — наведение, фокус;
- `200ms` — раскрытие.

Функция: `ease-out`. Анимация не декоративная: она объясняет изменение состояния.

Отдельная группа — **анимации заглушки**. У них нет функции «отклик на действие», они показывают,
что работа идёт, и объясняют метафору роста, поэтому длиннее и цикличнее:

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--animate-march` | `march 2.4s cubic-bezier(0.4, 0, 0.2, 1) infinite` | Бегущая полоса прогресса |
| `--animate-pulse-soft` | `pulse-soft 2.8s ease-in-out infinite` | Пульс статуса «идёт сборка» |

Анимации SVG-иллюстрации живут в слое `components` (им нужен `pathLength` и `transform-box`):

| Класс | Значение | Назначение |
| --- | --- | --- |
| `.growth-line` | `draw 2.6s` + `stroke-dasharray/offset` | Стебель «прорисовывается» один раз |
| `.leaf` | `leaf-unfold 1.4s` | Лист раскрывается от основания |
| `.ripple-ring` | `ripple 6.5s infinite` | Волны от центра, две в противофазе |
| `.drift-dot` | `drift 6s linear infinite` | Точки поднимаются и растворяются |
| `.breathe` | `breathe 7s infinite` | Мягкое дыхание свечения |

**Логотип** (`src/app/shell/Logo.tsx`) — единственная цикличная анимация вне заглушки, обоснование в
`direction.md` §7.2. Цикл один на все элементы (4.8s), поэтому вспышка уровня происходит синхронно:

| Класс | Значение | Назначение |
| --- | --- | --- |
| `.logo-spark` | `logo-spark 4.8s infinite` | Искра-сегмент (7% пути) проходит кривую роста |
| `.logo-node` | `logo-node 4.8s infinite` | Верхняя точка «вспыхивает» на приходе искры |
| `.logo-halo` | `logo-halo 4.8s infinite` | Свечение у верхней точки усиливается |
| `.logo-ripple` | `logo-ripple 4.8s infinite` | Волна от верхней точки |
| `.logo-start` | `logo-start 4.8s infinite` | Нижняя точка чуть ярче в момент прибытия |

**Входная страница** (`src/styles/landing.css`) добавляет два типа движения: одноразовое появление
и циклическую жизнь «Искры».

| Класс / кейфрейм | Значение | Назначение |
| --- | --- | --- |
| `.mask-line > span` | `line-rise 900ms` | Строки hero поднимаются из маски при загрузке |
| `.hero-fade` | `hero-fade 700ms ease-out 420ms forwards` | Текст hero проявляется после заголовка |
| `.reveal-child` | `opacity/transform 600ms` + `IntersectionObserver` | Секция проявляется при входе в экран |
| `.level-flash` | `level-flash 900ms` | Вспышка при повышении уровня |
| `.gain-pop` | `gain-pop 900ms` | Прибавка XP «отлетает» от строки привычки |
| `.spark-breathe` | `spark-breathe 6s infinite` | Дыхание ауры персонажа |
| `.spark-pulse` | `spark-pulse 4s infinite` | Пульс ядра |
| `.spark-mote` | `spark-mote 4.4s linear infinite` | Искры вокруг на 6-м уровне |
| `.spark-arm` | `spark-arm 5.5s infinite` | Лёгкое движение рук |
| `.spark-wing` | `spark-wing 3.2s linear infinite` | Крылья на 7-м уровне |

Циклические анимации «Искры» — такое же исключение, как логотип: персонаж воплощает текущий
уровень, поэтому его жизнь читается как состояние, а не как украшение. Амплитуда мала, период
длинный; при `prefers-reduced-motion` все `animation` отключаются, форма и числа остаются.

Правило: цикличные анимации допустимы только там, где состояние действительно продолжается
(заглушка, загрузка, персонаж-уровень). В рабочих экранах они не используются — там движение
только по событию. Исключения — **логотип** в хедере и **«Искра»** на входной странице; их
обоснование зафиксировано в `direction.md` §7.2–7.3.

`prefers-reduced-motion` — отключает переходы и анимации. У анимаций заглушки начальное состояние
(`opacity: 0`, `scale`) задаётся кейфреймом с `both`, поэтому при отключении элемент возвращается к
обычным стилям и **остаётся видимым**: стебель рисуется целиком (`stroke-dasharray: none`), листья
и точки видны. Логотип при отключённом движении показывает кривую целиком, без искры и волны.
Проверено в Playwright с `emulateMedia({ reducedMotion: "reduce" })`.

## 7. Темы (структура, реализация позже)

Токены семантические, поэтому светлая тема и темы ступеней — **смена значений**, не правка
компонентов. На корне закладывается атрибут:

```html
<div data-stage="beginning" class="app"> ... </div>
```

Темы ступеней (по `docs/solo/overview.md`: «Начало пути», «Разгон», «Устойчивость», «Мастер
практики», «Вершина») позже переопределяют набор переменных через `[data-stage="..."]`. Сейчас
реализуется только базовая тёмная.
