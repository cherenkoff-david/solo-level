# Дизайн-токены

Источник истины для значений: **документ (`tokens.md`) для человека, `@theme` в CSS — исполняемая
копия.** При расхождении правится код, документ обновляется.

Палитра — **принята после визуальной сверки** (первая гипотеза, тёплый нейтральный `#100f0d`,
отвергнута: читалась коричневой). Текущие значения — палитра Reflect (`#030014` + лаванда), взятая
как цвет без его декора (см. `references/reflect.md`).

Реализация: Tailwind 4 CSS-first (`@theme`), переменные семантические.

---

## 1. Цвет

### База (тёмная тема)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-bg` | `#030014` | Фон приложения (глубокий фиолетово-чёрный, как у Reflect) |
| `--color-surface` | `rgba(255, 255, 255, 0.03)` | Поверхности: карточки, стеклянные слои |
| `--color-surface-raised` | `rgba(255, 255, 255, 0.06)` | Поднятая поверхность: модальные окна, меню, hover |
| `--color-border` | `rgba(255, 255, 255, 0.1)` | Границы, разделители |
| `--color-border-strong` | `rgba(255, 255, 255, 0.2)` | Границы при наведении/фокусе |
| `--color-text` | `#f4f0ff` | Основной текст (лавандовый off-white) |
| `--color-text-muted` | `#efedfd99` | Вторичный текст, подписи |
| `--color-text-faint` | `#efedfd52` | Отключённый текст, метки |

Фон дополняется **амбиентным свечением** (два статичных радиальных градиента фиолетового и
синего, `background-attachment: fixed`). Это не декор ради декора: свечение даёт стеклянному хедеру
что размывать, иначе `backdrop-blur` не читается на плоском фоне.

### Акцент и статусы

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-accent` | `#ba9cff` | Лаванда. Интерфейс: навигация, фокус, активные элементы |
| `--color-accent-muted` | `rgba(186, 156, 255, 0.14)` | Подложка под интерфейсный акцент |
| `--color-progress` | `#f0a020` | Amber. **Только доменные числа** (XP, уровень, ступень) |
| `--color-progress-muted` | `rgba(240, 160, 32, 0.14)` | Подложка под прогресс |
| `--color-danger` | `#e5484d` | Отмена действия, ошибка |
| `--color-focus` | `#ba9cff` | Кольцо фокуса (совпадает с интерфейсным акцентом) |

Правило: **два акцента с разной ролью**. Лаванда — интерфейс (куда я могу нажать), amber — прогресс
(доменные данные). Amber не применяется к элементам интерфейса; лаванда не применяется к XP и уровням.

### Проверка контраста (до подтверждения скриншотом)

| Пара | Контраст (расчётно) | Норма |
| --- | --- | --- |
| `text #f4f0ff` на `bg #030014` | ~18:1 | ≥ 4.5:1 ✓ |
| `text-muted #efedfd99` на `bg #030014` | ~7:1 | ≥ 4.5:1 ✓ |
| `accent #ba9cff` на `bg #030014` | ~9:1 | ≥ 4.5:1 ✓ |
| `progress #f0a020` на `bg #030014` | ~9:1 | ≥ 4.5:1 ✓ |
| `text-faint #efedfd52` на `bg #030014` | ~2.8:1 | только для отключённого/декоративного |

Числа расчётные (WCAG 2.1, относительная яркость). Перепроверяются инструментом при вёрстке.

## 2. Типографика

| Токен | Значение |
| --- | --- |
| `--font-sans` | `Inter, system-ui, -apple-system, sans-serif` |
| `--font-mono` | `JetBrains Mono, ui-monospace, monospace` |

`font-feature-settings` для Inter: `"cv10" on, "ss01" on` (альтернативные глифы, как в референсе).
Для чисел — `font-variant-numeric: tabular-nums`.

### Размеры

| Токен | Размер / межстрочный | Назначение |
| --- | --- | --- |
| `--text-xs` | 12px / 16px | Метки, бейджи |
| `--text-sm` | 13px / 18px | Вторичный текст |
| `--text-base` | 14px / 20px | **Плотные списки** (привычки), основной UI |
| `--text-body` | 16px / 24px | **Просторные блоки** (прогресс), ввод |
| `--text-lg` | 18px / 26px | Подзаголовки |
| `--text-xl` | 22px / 28px | Заголовки разделов |
| `--text-2xl` | 28px / 34px | Крупные числа прогресса |
| `--text-3xl` | 36px / 42px | Главные метрики |

Веса: `400` (текст), `500` (акцент, активные элементы), `600` (заголовки). Жирнее — не используем.

## 3. Радиусы

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--radius-sm` | 6px | Чипы, мелкие элементы |
| `--radius-md` | 8px | **Кнопки, контролы** |
| `--radius-lg` | 12px | **Карточки, панели** |
| `--radius-full` | 999px | Pill-элементы, круглые индикаторы |

## 4. Отступы

Шкала с шагом 4: `4 / 8 / 12 / 16 / 24 / 32 / 48`. Промежуточных значений «на глаз» не вводим.

## 5. Границы и тени

- Граница: `1px solid var(--color-border)`. Толстых рамок нет.
- Тень для всплывающих слоёв: `0 8px 24px rgba(0, 0, 0, 0.4)` — только для модалок и меню.
- Карточки тенью не отделяются: только границей и фоном (`surface` на `bg`).

## 6. Движение

- Длительности: `120ms` (наведение, фокус), `200ms` (раскрытие).
- Функция: `ease-out`. Анимация не декоративная: она объясняет изменение состояния.
- `prefers-reduced-motion` — отключает переходы.

## 7. Темы (структура, реализация позже)

Токены семантические, поэтому светлая тема и темы ступеней — **смена значений**, не правка
компонентов. На корне закладывается атрибут:

```html
<div data-stage="beginning" class="app"> ... </div>
```

Темы ступеней (по `solo-level-overview.md`: «Начало пути», «Разгон», «Устойчивость», «Мастер
практики», «Вершина») позже переопределяют набор переменных через `[data-stage="..."]`. Сейчас
реализуется только базовая тёмная.
